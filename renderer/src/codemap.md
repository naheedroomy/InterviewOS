# renderer/src/

## Responsibility

This folder is the source root of the `renderer` package — a Create React App (CRA) TypeScript template generated by `react-scripts` 5.0.1. It is a **nested/legacy package** relative to the root app (the root package runs the real Vite + Electron app). This folder holds the default CRA starter UI: a single `App` component that renders the React logo and a "Learn React" link. It is not wired into the root Electron app's runtime; it exists as a standalone CRA scaffold.

## Design

- **Build tooling**: `react-scripts` 5.0.1 (CRA) with TypeScript 4.9.5 and React 18.3.1. No custom webpack config — all defaults from CRA.
- **Entrypoint**: `index.tsx` uses `ReactDOM.createRoot` (React 18 concurrent root) to mount `<App />` inside `<React.StrictMode>` onto the `#root` DOM node defined in `renderer/public/index.html`.
- **Component tree**: single top-level `App` component (`App.tsx`) — a functional component returning a centered header with the spinning logo, an edit hint, and a link to reactjs.org. No state, props, hooks, routing, or data layer.
- **Styles**: plain CSS, no preprocessor or CSS-in-JS.
  - `index.css` — global reset: zero body margin, system font stack, monospace `code` font.
  - `App.css` — scoped `.App`, `.App-logo`, `.App-header`, `.App-link` classes plus a `@keyframes App-logo-spin` rotation animation gated behind `prefers-reduced-motion: no-preference`.
- **Assets**: `logo.svg` imported by `App.tsx` and rendered as the spinning logo.
- **TypeScript env**: `react-app-env.d.ts` references `react-scripts` for CRA-provided ambient types (SVG imports, etc.).

## Flow

- `index.tsx` → `ReactDOM.createRoot(#root)` → renders `<App />` in StrictMode → `App.tsx` renders static JSX (logo, text, link) styled by `App.css`/`index.css`.
- `reportWebVitals()` is invoked at startup; it lazily imports `web-vitals` and reports CLS, FID, FCP, LCP, TTFB only if a callback is supplied (default: no-op).

## Integration

- **Tests**: `App.test.tsx` uses `@testing-library/react` to render `<App />` and assert the "learn react" link is present. `setupTests.ts` imports `@testing-library/jest-dom` to register custom DOM matchers (e.g. `toBeInTheDocument`). Tests run via `npm test` → `react-scripts test` (Jest + jsdom). ESLint extends `react-app` and `react-app/jest`.
- **Bootstrap**: `renderer/public/index.html` provides the `#root` mount node and loads the bundled script. `npm start` / `npm build` are standard CRA scripts.
- **Relationship to root app**: per repo AGENTS.md, the root package is the main Vite + Electron app; `renderer/` is a nested/legacy package and is **not** part of the root app's runtime or build. It is effectively a standalone CRA starter and can be ignored for the main app's architecture.
